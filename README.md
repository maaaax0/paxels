# Paxels - NeoForge 1.21.11

This branch contains the NeoForge build for Minecraft 1.21.11.

For general project information, see the README on the main branch.

## Build

Use the included Gradle wrapper:

``powershell
.\gradlew build
``

The built JAR is copied to:

``text
release-jars/neoforge/
``
