# Paxels

Paxels is a Minecraft mod that adds all-in-one tools combining pickaxe, axe and shovel behavior in a single item.

## Features

- Adds paxels for wood, stone, copper, iron, gold, diamond and netherite.
- Mines blocks tagged for pickaxes, axes and shovels.
- Supports axe stripping and shovel path flattening.
- Supports hoe tilling while sneaking.
- Includes a dedicated creative tab and basic advancements.

## Branches

- `fabric-*` branches contain Fabric builds for specific Minecraft versions.
- `neoforge-*` branches contain NeoForge builds for specific Minecraft versions.
- Version branches keep their README short and branch-specific.

## Building

Use the included Gradle wrapper from the branch you want to build:

```powershell
.\gradlew build
```

Release JARs are stored in `release-jars/`.
